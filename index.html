Exportação e segurança dos dados

Os dados são armazenados no Supabase e acessíveis em qualquer dispositivo após login com a mesma conta. Exporte um backup por segurança. Para migrar da versão anterior, importe o JSON exportado por ela.

O link do aplicativo é público, mas os dados exigem login. Compartilhamento: usa o menu nativo do celular quando disponível (WhatsApp, e-mail etc.). O compartilhamento envia o texto do relatório; não dá acesso ao banco de dados. Para gerar PDF, use “Salvar como PDF / Imprimir”. Não armazene informações pessoais desnecessárias em relatórios compartilhados.

Nesta versão cada conta visualiza seus próprios dados. Para vários representantes na mesma carteira, será necessário implementar uma equipe com permissões específicas.

Zona de manutenção
